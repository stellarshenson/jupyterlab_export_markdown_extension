28. **Task - SVG DPI scale fix** (v1.2.11): Fixed blurry SVG-to-PNG conversion by using cairosvg `scale` parameter<br>
    **Result**: The `dpi` parameter in cairosvg has no effect on SVGs with pixel-based dimensions (which most SVGs use) - it only affects SVGs with physical units (cm, mm, in). Tested: an 800x400 SVG produced identical 800x400 PNG output regardless of `dpi=150` or `dpi=300`. The `scale` parameter is what actually controls pixel output. Fixed `extract_data_uri_images()` in `routes.py` to compute `scale = dpi / 96` (96 is default SVG DPI) and pass both `scale` and `dpi` to `cairosvg.svg2png()`. At svgDPI=150, this produces 1.56x resolution increase (e.g. 800x400 -> 1250x625). Verified with the actual `header_banner.svg` from `project_proposal.md`
